This is a significant refactor of the existing 714-line script.js. The approach: keep ALL existing logic (timer, tasks, stats, settings, keyboard shortcuts) but update DOM selectors to match Plan 03's HTML, remove the old sound system, and add four new features.

STEP 1 -- Update DOM selectors:
- The existing code queries IDs like startBtn, resetBtn, minutes, seconds, etc. These IDs are preserved in the new HTML, so most getElementById calls stay unchanged.
- REMOVE: All references to the old nav system (sections querySelectorAll, navLinks intersection observer at lines 2-37). The new layout has no scrolling nav sections -- it is a single-viewport desktop.
- REMOVE: Animate.css class additions (animate__animated, animate__fadeIn at line 171). Use simple CSS opacity transitions instead.
- UPDATE: .sound-options, .sound-toggle-btn, .sound-option selectors are GONE. Replace with new music panel selectors.
- UPDATE: .timer-container references should point to the timer panel's .window-body
- UPDATE: section-based querySelector('.sound-recommendation') -- this no longer exists. Sound recommendations are replaced by the genre music system.

STEP 2 -- Remove old ambient sound system:
- Delete the entire ambient sound section: AudioContext creation, sound URLs (mixkit URLs), soundToggleBtn, soundOptions, soundOptionsButtons, playSound(), toggleSounds(), Web Audio API fetch/decode logic
- This is approximately lines 464-540 in current script.js

STEP 3 -- Add music genre system (replaces ambient sounds):
- Create a GENRES config array with 10 entries, each: { name: 'Lo-Fi', videoId: 'jfKfPfyJRdk' } (use long-play YouTube study music videos -- curate one per genre. Examples: Lo-Fi = 'jfKfPfyJRdk' (lofi girl), Jazz = a jazz study playlist video, etc. Use your best judgment for videoId selection -- these are background study music, so pick popular long-duration videos.)
- Create a hidden YouTube iframe player (same pattern as Songdle): div with id="ytMusicPlayer", 1x1px, position absolute off-screen
- Load YouTube IFrame API (add script tag dynamically or reference in HTML if not already present)
- Initialize YT.Player on the hidden iframe
- Genre button click handler: querySelectorAll('.genre-btn').forEach -- on click, load the genre's videoId into the YT player via loadVideoById(). Add .active class to clicked button, remove from others. Update now-playing-info text.
- Music play/pause button (#musicPlayBtn): toggles YT player playVideo/pauseVideo
- Volume slider (#volumeSlider): input event handler calls ytPlayer.setVolume(value)
- Store selected genre in localStorage for persistence

STEP 4 -- Add quote widget:
- Create QUOTES array with 15-20 inspirational study/productivity quotes. Each: { text: "...", author: "..." }. Include quotes from well-known figures (Einstein, Maya Angelou, Steve Jobs, etc.) about learning, persistence, creativity.
- On page load: pick a random quote, set #quoteText.textContent and #quoteAuthor.textContent
- #refreshQuote click handler: pick a new random quote (different from current), update text with a fade transition (opacity 0 -> update text -> opacity 1)

STEP 5 -- Add draggable panels:
- Create makeDraggable(panel) function using pointer events (from RESEARCH.md Pattern 3):
  - Get .window-titlebar as drag handle
  - On pointerdown: record offset, set panel z-index to ++zCounter (bring to front), add pointermove and pointerup listeners on document
  - On pointermove: update panel.style.left and panel.style.top
  - On pointerup: remove listeners
  - Add touch-action: none to titlebar CSS (already in styles.css from Plan 03)
- On init: querySelectorAll('.desktop-panel:not(.overlay-panel)').forEach(makeDraggable)
- For panels to be draggable, they need position: absolute on the .desktop container. BUT this conflicts with the CSS Grid default layout. Solution: panels start in grid layout (position: static). On first drag of any panel, switch ALL panels to position: absolute with their current computed positions (getBoundingClientRect). This gives a clean initial layout with drag-to-rearrange.
- On mobile (window.innerWidth < 768): do NOT call makeDraggable. Panels stay in grid/stack layout. Check on resize too.

STEP 6 -- Add minimize functionality:
- querySelectorAll('.window-btn.minimize').forEach -- on click, toggle .minimized class on the parent .desktop-panel. The CSS from Plan 03 handles hiding .window-body when .minimized is applied.

STEP 7 -- Wire stats and settings as overlay panels:
- Add a stats button somewhere accessible (e.g., in the timer panel header area or desktop header). On click: toggle #statsPanel visibility (remove/add display none).
- Add a settings button (gear icon in timer panel). On click: toggle #settingsPanel visibility.
- Close button (.window-btn.close) on overlay panels: hide the panel.

STEP 8 -- Preserve keyboard shortcuts:
- Space: start/pause timer (keep existing)
- R: reset timer (keep existing)
- Enter: add task if taskInput focused (keep existing)
- Esc: close overlay panels if open (update from old behavior)

STEP 9 -- Security: replace any innerHTML with user content using DOM APIs (createElement, textContent). The existing script.js uses innerHTML for task rendering (line ~347) and session counter (line ~80). Convert these to createElement/textContent per CLAUDE.md security rules.

All existing localStorage keys for tasks, settings, and stats MUST continue to work -- do not change key names. Users should not lose data after the redesign.
