   - Stage 2 LAUNCH (1-2.5s): Remove "charging", add "launching". Set stage text to "Launching...". After 1.5s, move to stage 3.

   - If animation is already in HOVER stage, immediately transition to final stage

7. Error handling: on fetch catch, same as error path above.
