<task type="auto">
  <name>Task 2: Create shared/animations.js ES Module with GSAP helpers and skeleton utilities</name>
  <files>shared/animations.js</files>
  <action>
Create `shared/animations.js` as an ES Module with:

1. **Reduced-motion guard** (ANIM-01 JS layer):
   ```javascript
   const prefersReducedMotion = window.matchMedia('(prefers-reduced-motion: reduce)');
   export function shouldAnimate() {
     return !prefersReducedMotion.matches;
   }
   ```

2. **Timing constants** (matching CSS custom property values):
   ```javascript
   const TIMING = {
     interaction: 0.2,
     entrance: 0.6,
     staggerDelay: 0.1,
   };
   const EASING = 'power2.out';
   ```

3. **Scroll reveal functions** (ANIM-04 foundation, requires GSAP on window):
   - `revealOnScroll(selector, options = {})`: Guards with shouldAnimate(). Registers ScrollTrigger plugin. Uses gsap.from with opacity:0, y:30, duration TIMING.entrance, ease EASING, scrollTrigger with start 'top 85%' and once:true. Merges options into scrollTrigger config.
   - `staggerCards(selector)`: Guards with shouldAnimate(). Uses ScrollTrigger.batch() with onEnter that gsap.from's the batch with stagger TIMING.staggerDelay. start 'top 85%', once:true.

4. **Skeleton loading utilities** (ANIM-03 foundation):
   - `showSkeleton(container)`: Adds 'is-loading' class, removes 'is-loaded' class, returns Date.now() timestamp.
   - `hideSkeleton(container, startTime)`: Calculates elapsed time, enforces 400ms minimum display, then removes 'is-loading' and adds 'is-loaded' class after remaining delay.

5. **Init helper**:
   - `initScrollAnimations(config)`: Takes object with optional selectors for sections, cards. Calls revealOnScroll/staggerCards for each. This is the main entry point pages call after GSAP loads.
   - Must wait for hero curtain to finish before initializing scroll animations on the portfolio shell. Accept an optional `afterEvent` parameter (CSS selector to listen for transitionend on before init).

All GSAP calls must check `typeof gsap !== 'undefined'` before using gsap, logging a warning if missing (defensive, not crashing). All animation functions must call shouldAnimate() and return early if reduced motion is preferred.

Export: shouldAnimate, revealOnScroll, staggerCards, showSkeleton, hideSkeleton, initScrollAnimations.
